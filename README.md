One original line roasting the gadget I use every day — my AirPods, which die in one ear first, mid-sentence, like they're taking turns ghosting me. Written for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty ($5, top 3 paid).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes a single 85-character line to `out/entry.txt`.
